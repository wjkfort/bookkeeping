# 记账桌宠 · 10 秒动作提示词（可直接粘贴到视频生成平台）

改自 [PC2005-cloud/dsh-pet](https://github.com/PC2005-cloud/dsh-pet) 的
`prompts/桌面宠物 10 秒动作提示词.md`（配方：绿幕规范 + 按秒分解）。
动作设计针对**记账场景**：记录、纠错、核对、逾期、余额、报错。

---

## 一、生成前必读

### 1. 每段视频都要带上「通用前缀」

前缀是这套素材能用的**根本原因**——它锁死了绿幕色值、人物位置、首尾帧，
所以 60 段视频才能无缝合成为一个角色。**每个动作都要把前缀 + 该动作的正文一起粘贴。**

### 2. 源视频规格（照抄仓库流水线的输入要求）

| 项 | 值 |
|---|---|
| 比例 | 16:9 |
| 背景 | 纯绿幕，严格 `#00FF00`，无阴影/渐变/边框 |
| 分辨率 | 1280×720（平台若只给 720p 或 1080p 都可以，后续会归一化） |
| 帧率 | 24fps |
| 时长 | 10 秒 |
| 首尾帧 | **都必须是参考图那张标准正面站立**，无道具残留 |
| 人物位置 | 头顶 ≈ 画幅 20%、脚底 ≈ 85%、左右边缘 25%~75% |
| 安全边距 | 任何部位/道具离画幅边缘 ≥10% |

### 3. 参考图怎么用

- 平台若支持「参考图 / 首帧图」：**喂你那两张图**（正面站姿那张最合适）。
- 平台若不支持：在提示词开头加一句
  `角色严格参考我上传的图片：Q版蓝发鲸鱼娘女仆装的正面全身站姿。`
- ⚠️ **要事先确认**：这套提示词假设角色是"Q版、正面、全身可见、双足站立"。
  如果你的参考图是**坐姿**或只有半身，首尾帧的"标准正面站立"就对不上，
  流水线的归一化（按站立高度 900px 对齐）会失准。**坐姿需要改写前缀**，见第五节。

### 4. 出片后的处理

拿到绿幕 mp4 后，走仓库那三步（本机可复现，`scripts/` 下有现成脚本）：

```
绿幕 mp4 → watermark_step01.py（去水印遮罩）
         → chroma_step02.py（HSV 色相抠像成透明）
         → normalize_step03.py（2160×1215，站立高度统一 900px）
         → encode_thumbs.py（640×360 VP9-alpha webm，播放用）
```

**注意**：`chroma_step02.py` 用的是 **HSV 色相判定**而不是 `chromakey`——
因为色度距离会把蓝色/白色一起抠掉，而你的角色主色正是蓝和白。这是它的关键改进。

## 二、通用前缀（原样复制，接在每个动作正文前）

```text
【绝对空间与边界约束强制命令】
视频比例 16:9，背景必须为纯粹的绿幕色（标准 Chroma Key Green，颜色严格统一为 #00FF00），
无任何阴影、杂物、渐变或边框，背景本身即为单一纯色块。
人物位置与大小强制固定：人物必须完完全全处于画面正中心偏下位置。人物头顶始终处于画面
垂直方向约 20% 的位置，脚底始终处于画面垂直方向约 85% 的位置，最左和最右边缘始终处于
画面水平方向约 25% 和 75% 的位置。不同视频之间的人物大小、位置、比例必须完全一致，
不允许有任何偏差。
人物周围缓冲区（防裁切）：人物头顶距离画幅顶边至少保留 15% 画幅高度的绿色空间，脚底
距离画幅底边至少保留 10% 画幅高度的绿色空间，身体左右两侧距离画幅边缘至少保留 10%
画幅宽度的绿色空间。
【画幅安全红线（统一数值，全程强制）】：全库安全缓冲统一为画幅任意一边的 10%。动作全程
任何一帧，角色任何身体部位（顶部的呆毛、耳侧的鳍饰、底部的裙摆与鲸鱼尾巴、手脚与指尖）
以及所有道具与特效对象，在最高点/最外点都必须与画幅对应边缘保持 ≥10% 画幅宽/高的安全
间距；绝对禁止任何部位或对象接触、触碰、超出或被裁剪。动作全程必须在画幅内部完成。
【绝对居中锚点（强制）】：人物双脚落点坐标恒定为屏幕正中央，全程不允许产生 X 轴或 Y 轴
平移位移（仅允许轴心旋转、原地跳跃、脚尖原地点地）。无论出现多大体积的道具或场景对象，
角色与对象的组合视觉重心必须始终保持在画面水平正中；严禁为了容纳道具或对象而把角色整体
向左右移动、向后移动或靠向画幅边缘。
【大物件构图规则（强制）】：出现较大体积物件（高度＞画幅 30% 时）——① 物件必须位于角色
正前方 / 正上方 / 环绕角色轴线，并与角色共用画面水平中心线，禁止放成"身侧/一侧偏左偏右"
导致画面重心偏移；② 若物件受画幅所限放不下，宁可把物件 Q 版缩小以整体入画并保持在安全区
内，绝不移动人物来腾空间；③ 角色与物件必须同框，人物始终占据画面中心主干位置，双脚与
原点静止。
【"无→有→无"道具闭环（强制）】：所有含道具/特效/交互对象的视频，入场第一帧必须是与参考图
完全一致的标准正面站立、画面干净——无任何道具、无任何特效、无任何对象（仅纯绿幕背景 +
角色本体）；道具与对象一律由角色以魔法手势从无到有、由虚到实地渐进凝聚生成（先出现半透明
虚影轮廓，约 0.5~1 秒后凝实为实体），绝不直接出现在起始帧；并在动作结束前从有到无、由实
到虚地渐次消散（约 0.5~1 秒化为光点淡去），使画面回到无任何道具的标准正面站立。任何一帧
都不得凭空直接出现未经生成过程的道具，最终帧不得残留任何道具或特效。
【侧身互动 ≠ 构图横移（强制）】：需要侧身/转身面向物件的互动，一律指角色原地轴心转动上身、
头部或脚尖原地点地转向来面向物件，双脚与画面中心原点始终保持静止、不横移、不后移、不靠边；
凡"退后、后退、后移、走到一侧、挪到旁边、偏右/偏左站位"等会造成整体位移的描述一律视为
违规，应改写为原地轴转或原地重心微调。
所有视频必须以参考图的标准正面图为第一起始帧（此帧画面干净、无任何道具或特效），并在视频
最后一秒（第 10 秒结束时）彻底恢复到与第一帧完全一致、无道具残留的标准正面站立姿态。
不同视频之间的绿色背景色值必须完全一致，不允许有色差。
```

> 角色本体描述请统一（把下面这句里的特征换成你参考图上的实际特征，之后**所有动作都沿用同一句**，避免角色漂移）：
> `Q版蓝发鲸鱼娘女仆装，蓝色渐变长发、头戴白色荷叶边女仆头饰、鲸鱼鳍状耳朵、身后一条鲸鱼尾巴、深蓝长袖连衣裙配白色围裙、白色连裤袜与深蓝玛丽珍鞋。`

## 三、第一批（5 段）——覆盖桌宠最小可用状态机

这 5 段就能跑通"闲置 → 想事 → 干活 → 成功/失败"，也正好对应你项目里已有的状态。

### 1. `待机呼吸`（idle 池）

```text
Q版蓝发鲸鱼娘女仆装原地站立，身体呈现自然、有节奏的轻微上下起伏（呼吸感）。双眼平视
前方，每隔 3~5 秒完成一次轻快眨眼。头顶的呆毛和身后的鲸鱼尾巴进行极其微小且舒缓的左右
摆动。无位移，无切边，动作自然，全身结构完整保留在画面中央。

0~3秒：身体以极轻微幅度上下起伏模拟呼吸，每隔约 2 秒眨眼一次，双臂自然垂放。
3~7秒：头部以极小幅度向左、向右缓慢转动，仿佛在环顾四周，头顶呆毛随之柔顺摆动，身体
重心始终在原位。
7~10秒：头部缓缓回正，呼吸恢复平稳。第 10 秒结束时与第一帧标准正面站立完全一致。

最终帧：标准正面站立，双手自然垂落，目光平视，表情温和宁静，无位移、无道具残留。
```

### 2. `思考翻账本`（thinking 池）— 对应 AI 请求中

```text
Q版蓝发鲸鱼娘女仆装从身前凭空变出一本浅蓝色封面的小账本，双手捧在胸前，低头翻看并
认真思考，眉心微蹙、目光在页面上移动，偶尔歪头、指尖轻点下巴。翻看几页后灵光一现，
表情舒展，随后合上账本，账本淡出消失，恢复标准正面站立。

0~2秒（变出账本）：标准正面站立。双手从身前以魔术般的动作凭空变出一本小账本（约画幅
宽度 15%，浅蓝色封面、带金色小装饰），双手捧至胸前，低头看向账本，表情从平静转为专注。
2~6秒（翻看与思考）：左手托住账本底部，右手一页页轻轻翻动（约每 1.5 秒翻一页）。头部
随阅读轻轻左右移动，眉心微蹙，眼神专注。鲸鱼尾巴安静垂在身后，呆毛微微晃动。
6~8秒（想通了）：翻页动作停下，头部抬起看向斜上方（思考状），歪头约 0.8 秒；随后眼睛
亮起、表情舒展，右手食指轻点一下账本页面，像是确认了什么。
8~10秒（合上账本 → 恢复）：双手合上账本，账本在合拢过程中由实到虚逐渐淡出为光点消失。
头部回正，表情从专注收敛为温和宁静的浅笑，双手自然垂落。第 10 秒结束时彻底恢复为
标准正面站立。

最终帧：标准正面站立，双手自然垂落，目光平视，表情温和宁静，账本完全消失，无位移。
```

### 3. `低头记一笔`（tool 池）— 对应工具执行中

```text
Q版蓝发鲸鱼娘女仆装从身侧凭空变出一本小账本和一支笔，低头专注地在上面写下一笔记录，
头部随书写节奏轻快有韵律地小幅摇摆，仿佛在哼着小曲享受记账的过程。写完最后一笔后
满意地点点头，合上本子，本子和笔一同消失，恢复标准正面站立。

0~2秒（变出本子和笔）：标准正面站立。右手从身侧凭空变出一本小账本（约手掌大小，浅蓝
或白色封面、带可爱装饰），左手变出一支笔（彩色笔身、顶端带小装饰）。双手捧至胸前，
低头看一眼本子，表情期待带笑。
2~6秒（书写与摇头）：左手托住本子底部，右手握笔书写，笔尖在本子上移动（约每秒 1~2 次
运笔动作）。头部以颈部为轴心有节奏地小幅左右摇摆（每次约 5°~8°，约每 1 秒一个左右
循环），身体随之微微律动，表情专注愉悦、眼睛微眯、嘴角上扬，呆毛与尾巴轻轻摆动。
6~8秒（抬头思考 → 继续写）：书写暂停，抬头看向斜上方，歪头思考约 0.5 秒；随后仿佛想
通了，头部回正继续埋头书写，尾巴愉快地摆动。
8~10秒（写完合本 → 恢复）：做一个收笔动作，低头满意地看一眼，轻轻点头，双手合上本子，
笔也放下。本子与笔同时由实到虚淡出消失，头部抬起回正，目光平视前方，表情从满足转为
温和宁静，双手自然垂落。第 10 秒结束时彻底恢复为标准正面站立。

最终帧：标准正面站立，双手自然垂落，目光平视，表情温和宁静，本子和笔完全消失，无位移。
```

### 7. `逾期提醒`（高优先级，对应有逾期订阅）

```text
Q版蓝发鲸鱼娘女仆装突然竖起鲸鱼鳍状耳朵，头顶弹出一个半透明的感叹号，表情从平静
```

同时把每个动作里的"正面站立"全部替换为"标准坐姿正面"、"脚底"替换为"坐姿底边"。

### 抠像脚本

`pet-video/make-green.py`（逐帧自适应，可处理一段里混着不同底色）：

```bash
/usr/bin/python3 pet-video/make-green.py <输入.mp4> <输出.mp4>
```

- 绿底：`(G − max(R,B)) > 25`（偏灰绿也适用）
- 黑底：最大通道 ≤ 20（只认近纯黑，不吃角色的深蓝描边）
- 近白底：角部中位为白 **且** 全图近白占比 ≥ 50%
- 过渡帧：识别不出底色 → 用其后第一张可用画面顶替
- 一律用**从画布边缘洪泛**，所以白围裙/白头饰/深蓝裙发不会被误删
- 附带 despill，压掉绿幕在角色边缘的反射

> 注意：这台机器有两个 Python —— `/usr/bin/python3` 有 numpy（脚本用它），
> `/usr/local/bin/python3` 有 PIL。两者库不互通。
